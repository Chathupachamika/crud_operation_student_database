# CRUD Operation - Student Database 📚

A simple CRUD (Create, Read, Update, Delete) application for managing student data. This project is built with Java for the back-end and JavaScript/HTML/CSS for the front-end.

## 🚀 Features

- Manage student records (add, update, delete, view)
- Front-end UI with basic HTML, CSS, and JavaScript
- Back-end functionality using Java

## ⚙️ Installation

To get started with this project:

1. Clone the repository:
    ```bash
    git clone https://github.com/Chathupachamika/crud_operation_student_database.git
    ```

2. Navigate to the project directory:
    ```bash
    cd crud_operation_student_database
    ```

3. Install dependencies for the back-end:
    - For back-end, use your preferred Java IDE or command line tools to build the Java project.

4. Install dependencies for the front-end:
    ```bash
    npm install
    ```

5. Start the server:
    ```bash
    npm run start
    ```
